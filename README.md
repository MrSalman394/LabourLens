# LabourLens

LabourLens is an intelligent labor analytics and monitoring platform developed as a Final Year Project (FYP).

## Project Structure

```text
LabourLens/
│
├── apps/
│   ├── web/              # Next.js web application
│   ├── mobile/           # Flutter mobile application
│   └── api/              # NestJS backend
│
├── services/
│   └── ai/               # Python AI/ML service
│
├── database/             # Database scripts, migrations, and schemas
├── docs/                 # FYP documentation and design specs
├── infrastructure/      # Docker, Kubernetes, and deployment configs
├── scripts/              # Automation and setup scripts
│
└── .git/                 # Git repository
```

## Tech Stack Overview

- **Web Frontend**: [Next.js](https://nextjs.org/) (React, TypeScript, Tailwind CSS)
- **Mobile Frontend**: [Flutter](https://flutter.dev/) (Dart)
- **Backend API**: [NestJS](https://nestjs.com/) (Node.js, TypeScript)
- **AI/ML Service**: [Python](https://www.python.org/) (FastAPI / Flask, PyTorch / TensorFlow)
- **Database**: PostgreSQL / MongoDB
- **Infrastructure**: Docker & Docker Compose
